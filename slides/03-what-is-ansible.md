# 🧩 Что такое Ansible

**Ansible** — открытый инструмент автоматизации от Red Hat: настройка серверов, установка ПО, деплой приложений и оркестрация — **одним описанием на YAML**.

### Ключевые идеи

| | Принцип | Суть |
|---|---|---|
| 🚫🤖 | **Agentless** | Ничего ставить на серверы не нужно — только SSH и Python |
| 📝 | **Declarative** | Описываем *что* должно быть, а не *как* это сделать |
| 🔄 | **Idempotent** | Повторный запуск безопасен: уже настроенное не меняется |
| 👀 | **Читаемость** | YAML понятен даже без опыта программирования |

> [!NOTE]
> Примеры применения: установка пакетов, управление пользователями, конфиги, обновления, деплой, настройка облаков и сети.
